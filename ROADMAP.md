# Learning roadmap

Each phase is a self-contained workshop. Later guides stay short until we reach them so the course can adapt to actual learning.

| Phase | Workshop | Outcome |
|---|---|---|
| 0 | [Setup and safe connection](phases/phase-00-setup/README.md) | Check tools and inspect session context without creating objects |
| 1 | [First Snowflake objects](phases/phase-01-first-objects/README.md) | Create one warehouse, database, table, and view |
| 2 | [Synthetic car template](phases/phase-02-car-template/README.md) | Build `CAR_PROD` and validate with Python |
| 3 | [Clone and isolation](phases/phase-03-clone-isolation/README.md) | Clone and prove isolation |
| 4 | [Roles and publication](phases/phase-04-rbac-publication/README.md) | Separate ownership, team access, and consumption |
| 5 | [Lifecycle automation](phases/phase-05-lifecycle-python/README.md) | Add guarded refresh/expiry behavior |
| 6 | [Terraform foundations](phases/phase-06-terraform/README.md) | Manage stable infrastructure declaratively |
| 7 | [Self-service request](phases/phase-07-self-service/README.md) | Validate and preview a YAML request |
| 8 | [Scheduling and review](phases/phase-08-scheduling/README.md) | Schedule lifecycle and rebuild/clean up the POC |

Workshop loop: learn → predict → choose UI/script → run one task → inspect → record → checkpoint.
